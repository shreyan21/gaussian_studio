QUICK GUIDE

Capture quality controls 3D quality.

  1. Keep scene still. Move only camera. Do not rotate object between shots.
  2. Use 20-40 ordered views. Walk smooth circle; keep 70-85% overlap.
  3. Lock capture. Same zoom, focus, exposure, lighting, and distance.
  4. Avoid hard subjects. Reflections, glass, motion, blur, and plain texture break photogrammetry.
