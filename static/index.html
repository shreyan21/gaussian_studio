QUICK GUIDE

From photograph to perspective.

  1. Choose a clear photo. Rooms, buildings and landscapes show the depth effect well. Use a normal photo, not an extreme panorama.
  2. Pick a model. Depth Anything is lightweight and Apache licensed. SHARP directly predicts Gaussians, uses more memory and has a research-only model licence.
  3. Create, then explore. Drag in the viewport to orbit. Right-drag or Shift-drag to pan. Scroll or use + / − to zoom. Arrow keys rotate and R resets.
  4. Export your result. The .ply contains real 3D Gaussian positions, scales, rotations, opacity and colours. “Save image” captures the current view.
One image has a limit.

The camera can move through 360°, but neither pipeline recovers the true hidden sides. Nearby viewpoints look best. Accurate complete geometry needs multiple real views.

First-time installation needs internet to download dependencies and weights. Inference and viewing then run locally. See README.md for workstation setup.
